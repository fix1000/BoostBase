# BoostBase Roadmap

## Phase 1 - Core Repertoire

- Application initialization
- Store songs
- Load songs
- Add songs
- Display songs
- Update songs
- Delete songs
- Archive songs

## Phase 2 - Search & Filtering

- Search by title
- Search by artist
- Search by tags
- Filter by genre
- Filter by other song metadata

## Phase 3 - Setlists

- Create setlists
- Add songs to setlists
- Remove songs from setlists
- Change song order
- Save setlists
- Delete setlists

## Phase 4 - Integrations & Intelligence

- Spotify integration
- Statistics
- AI-generated setlists

## Phase 5 - Cloud & Mobile

- Cloud synchronization
- Web interface
- Mobile-friendly application
